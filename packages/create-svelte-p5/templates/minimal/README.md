## Develop

```sh
npm install
npm run dev
```

`npm run check` type-checks with svelte-check and `npm run build` makes a production build.

## Where to go next

- `src/routes/+page.svelte` holds the sketch.
- [Getting started guide](https://github.com/edw1nzhao/svelte-p5/blob/main/docs/getting-started.md)
- `svelte-p5-components` adds `Sketch`, `FPSMonitor` and more; the `components` template shows them.
